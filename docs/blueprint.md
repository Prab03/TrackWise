# **App Name**: TrackWise

## Core Features:

- Income Tracking: Allow users to input their income sources and amounts.
- Expense Categorization: Enable users to categorize expenses (e.g., food, rent, transport).
- Visual Reporting: Generate visual reports (charts and graphs) of income vs expenses.
- AI Budgeting Assistant: AI tool to analyze spending patterns and provide personalized budgeting suggestions.
- Budget Alerts: Set budget limits for each category and receive alerts when nearing the limit.
- Recurring Expenses: Allow users to create recurring expense entries (e.g., rent, subscriptions).
- Dashboard Overview: Provide a summary view of current balance, income, expenses, and remaining budget.

## Style Guidelines:

- Primary color: Deep blue (#3F51B5) to convey trust and security.
- Background color: Light gray (#F5F5F5) to provide a clean and neutral backdrop.
- Accent color: Teal (#009688) for interactive elements and key highlights.
- Body and headline font: 'Inter' (sans-serif) for a modern and readable interface.
- Use minimalist, line-based icons to represent expense categories and actions.
- Clean and intuitive layout with a focus on readability and ease of navigation.
- Subtle transitions and animations to enhance user experience, such as chart animations and loading indicators.
